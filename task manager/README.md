# 📋 Task Manager

Ek powerful aur modern task management web app jo HTML, CSS aur JavaScript se bana hai. Isme aap tasks add kar sakte ho, edit kar sakte ho, categories assign kar sakte ho, aur apna data export/import bhi kar sakte ho.

## 🚀 Live Demo
👉 **[Click here to view live app](https://ayusharav00258-ui.github.io/task-manager/)**

## ✨ Features

### Core Features
- ✅ **Add Task** — priority aur deadline ke saath
- ✅ **Edit Task** — kisi bhi task ko update karo
- ✅ **Complete / Pending** — status toggle karo
- ✅ **Delete Task** — kaam khatam, task hatao
- ✅ **Filter** — All / Pending / Completed

### Advanced Features
- 🔍 **Search** — turant task dhundho
- 🏷️ **Categories** — Work, Personal, Study, General tags
- 📊 **Task Counter** — live dashboard (total/completed/pending)
- ⏰ **Overdue Highlight** — deadline cross hone pe red
- 🌙 **Dark Mode** — eye-friendly night mode
- 📤 **Export / Import** — JSON backup aur restore
- 🎨 **Smooth Animations** — fade-in, hover effects

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Storage:** LocalStorage (browser mein data save)
- **Deployment:** GitHub Pages
